# Business Predictive Analytics (INFO3018)

This repository contains my coursework, case studies, and practical implementations for **INFO3018 Predictive Analytics** at Deakin University. The core focus of this work is applying statistical modeling and machine learning techniques to drive data-backed business decisions.

## 📊 Core Focus Areas
* **Supervised Machine Learning:** Training predictive models to evaluate risk, customer behavior, and financial indicators.
* **Time-Series Forecasting:** Analyzing historical data to project future business trends and metrics.
* **Business Analytics Pipelines:** Developing end-to-end workflows from raw data preprocessing to final strategic insights.

## 🛠️ Environment & Tools
* **Language:** Python 3.x
* **Core Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn
* **Data Environment:** Jupyter Notebooks / Python Scripts
